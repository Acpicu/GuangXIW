# GuangXIW · 关系网

**SJ Lens 的电脑端 / 手机端互通辅助工具。**
手机负责采集，电脑负责把人和关系摊开看，两端通过一份 JSON 文件对齐。

![icon](icon.png)

## 这是什么

一个用来梳理「谁和谁有关系」的小工具：人、组织、地点、账号、事件都能变成一个节点，
节点之间用「亲属 / 同事 / 同学 / 好友 / 资金 / 同平台」这类关系连起来，可以标强度和证据编号。

- **单文件便携**：`GuangXIW.exe` 只有 1.4 MB，双击就能开，不装运行库（用系统自带的 WebView2 内核）
- **数据在本地**：全部存在本机，不联网、不上传
- **和 SJ Lens 互通**：导入手机备份，导出关系摘要回手机

## 快速开始

1. 双击 `GuangXIW.exe`
2. 画布空白处**双击**新建人物，或者点底部「人物」
3. 点卡片 → 右侧「建立关系」→ 填对方名字（不存在会自动建）→ 选类型和强度
4. 顶栏「归整」把图挪回正中；「路径」查两个人之间的最短关系链

> 界面里两个抽屉默认收起：`Ctrl+L` 打开清单，`Ctrl+K` 打开详情。

## 功能

| 分类 | 说明 |
|---|---|
| 实体 | 人物 / 组织 / 地点 / 账号 / 其他，可上传头像、加标签 |
| 账号 | 每个实体可挂多个平台账号（抖音、快手、B站…） |
| 其他信息 | 键值对：常去、喜好、车牌，想记什么记什么 |
| 记录 | 带时间戳的事件条目，可改可删；左栏「时间线」按天汇总所有人的记录 |
| 关系 | 类型 + 强度 1–5 + 证据号（对应 SJ Lens 数据本的 E-xxx）+ 备注 |
| 视图 | 力导向 / 环形 / 按连接数；滚轮缩放、拖拽、悬停高亮邻居 |
| 分析 | 最短关系链（BFS）、关键人物（按连接数排序） |
| 文件夹 | 一个调查目标一个文件夹，互不干扰 |
| 导出 | JSON 备份 / Markdown 报告 / 给 SJ Lens 的关系摘要 |

## 和 SJ Lens 配合

```
手机 SJ Lens  ──导出备份──▶  电脑 GuangXIW（导入，得到人物节点）
电脑 GuangXIW ──导出关系摘要──▶  手机 SJ Lens（数据本 → 关系网，图谱页可见）
```

送文件到手机用 `推送手机.bat`（USB + ADB，不联网）：

```bat
adb push %USERPROFILE%\Downloads\guangxiw-relations-*.json /sdcard/Download/
```

## 自己编译

不需要装 Visual Studio，用 Windows 自带的 C# 编译器：

```bat
构建 GuangXIW.bat
```

`index.html` 与 WebView2 托管库会作为资源内嵌进 exe，运行后释放到
`%LOCALAPPDATA%\GuangXIW\app`。

## 文件说明

| 文件 | 作用 |
|---|---|
| `GuangXIW.exe` | 成品，双击即用 |
| `index.html` | 应用本体（界面 + 逻辑，单文件） |
| `launcher.cs` | 宿主：WebView2 窗口、单实例、深色标题栏 |
| `构建 GuangXIW.bat` | 重编译脚本 |
| `推送手机.bat` | 用 ADB 把关系摘要推到手机 |
| `PLAN.md` | 设计与迭代记录 |
| `sample-relations.json` | 关系摘要格式样例 |

## 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl + K` | 显示/隐藏右侧详情 |
| `Ctrl + L` | 显示/隐藏左侧清单 |
| `Esc` | 取消选中 / 清除关系链高亮 |
| `Delete` | 删除选中的实体 |
