# GuangXIW

SJ Lens 的电脑端关系网工具。单文件 exe，数据在本机。

## 用

双击 `GuangXIW.exe`。

- 双击画布空白处新建人物
- 点卡片 → 右侧「建立关系」
- `Ctrl+K` 详情 / `Ctrl+L` 清单 / `Esc` 取消选中
- 「路径」查最短关系链，「归整」把图挪回正中

## 与手机互通

电脑「导出 → 给 SJ Lens（手机）」→ 双击 `推送手机.bat`（ADB）→ 手机数据本「关系网」导入。

## 自己编译

`构建 GuangXIW.bat`（用系统自带 csc，不需要 Visual Studio）。
